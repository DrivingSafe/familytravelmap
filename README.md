# 우리 가족 여행일기

가족이 함께 다녀온 곳을 지도에 칠하고, 다음 여행을 계획하는 여행 다이어리. 서버 없이 `index.html` 한 파일로 동작하는 정적 웹앱이며, 홈 화면에 설치해 앱처럼 쓸 수 있습니다.

배포 주소: https://drivingsafe.github.io/familytravelmap/
배포 방법은 [DEPLOY.md](DEPLOY.md) 참고.

## 화면 구성

모바일은 하단 탭 3개로 나뉩니다.

- **지도** — 시·군·구 250곳을 칠하는 메인 화면. 검색, 확대/축소, 지역 선택
- **계획** — 다가오는 가족 여행 카드(D-day·숙소·교통·예산·체크리스트·사진)와 가족 구성원 관리
- **기록** — 달성률, 시·도별 탐험 현황, 여행 연대기, 배지

## 주요 기능

- 방문 / 가고 싶은 곳 표시, 지역별 날짜·제목·메모·만족도·참여 가족·사진(최대 3장)
- **시·도별 파스텔 컬러** — 방문한 지역이 시·도마다 다른 색으로 칠해져 지도가 조각보처럼 보입니다
- **시·도별 탐험 현황** — 17개 시·도의 진행률. 누르면 그 시·도로 지도가 이동합니다
- **여행 연대기** — 모든 기록을 연도별로 묶어 사진·별점과 함께 보여줍니다. 가족 구성원별로 필터링 가능
- **검색** — 시·도 이름(`서울`, `경남`)으로도 찾을 수 있고, 결과마다 소속 시·도를 표시해 `중구`처럼 6곳에 있는 이름도 구분됩니다. 영문명(`gangneung`), `수원시 장안구` 같은 띄어쓰기도 인식
- 여행 계획을 "다녀왔어요"로 완료하면 지도와 연대기에 자동 반영
- 지도를 PNG 이미지로 저장, 달성률 공유, 앱 링크 공유
- JSON 백업 / 복원 (마지막 백업 시각 표시)
- **PWA** — 홈 화면 설치, 서비스 워커가 지도 데이터까지 캐싱해 오프라인 동작

## 데이터는 어디에 저장되나

서버도 계정도 없습니다. 모든 기록은 **그 기기 브라우저의 localStorage**에만 저장됩니다.

| 키 | 내용 |
|---|---|
| `my-korea-journey-v2` | 지역 기록 (키 = 행정구역 코드) |
| `my-korea-journey-trips-v1` | 여행 계획 |
| `my-korea-journey-family-v1` | 가족 구성원 이름 |
| `my-korea-journey-familyname-v1` | 우리 가족 이름 |
| `my-korea-journey-lastbackup-v1` | 마지막 백업 시각 |

따라서 아빠 폰과 엄마 폰의 기록은 **자동으로 합쳐지지 않고**, 브라우저 데이터를 지우면 함께 사라집니다. 설정 화면에서 가끔 백업 파일을 내보내 두세요. 여러 가족이 같은 주소를 열어도 서로의 기록은 보이지 않습니다.

## 코드에서 주의할 점

- **기록 키는 지역 이름이 아니라 행정구역 코드**입니다. `중구`는 6개 시, `동구`는 6개 시에 있어(250곳 중 30곳이 이름 중복) 이름으로 저장하면 한 곳을 기록할 때 같은 이름의 다른 도시까지 칠해집니다. 예전 이름 기반 데이터는 열 때 자동 이관됩니다(`migrateDbToCodes`).
- **지도 투영은 `d3.geoMercator()`**. `geoIdentity()`는 위·경도를 평면 좌표로 취급해 한국 위도에서 지도가 가로로 약 1.24배 늘어나 눕혀 보입니다. 초기 범위는 감김 방향 문제를 피하려고 폴리곤 대신 `MultiPoint` 두 점으로 지정합니다.
- **`.district`에 `filter`(drop-shadow 등)를 걸지 마세요.** path 250개마다 오프스크린 렌더가 생겨 팬·줌이 3배 이상 느려집니다. 그림자는 지도 컨테이너에만 `box-shadow`로.
- **확대 배율에 따른 선 굵기는 JS로 매 프레임 다시 칠하지 말고** CSS `vector-effect: non-scaling-stroke`에 맡기세요.
- 움직이는 지도 위에 겹치는 요소의 `backdrop-filter`는 모바일에서 꺼져 있습니다(매 프레임 재합성 방지).
- CSS는 `:root` 토큰 → 기본 → 컴포넌트 → 화면별 → **모바일 한 블록** 순서입니다. 미디어 쿼리를 여기저기 새로 만들지 말고 마지막 블록에 모으세요.
- 버튼 안에는 `<div>`를 넣지 마세요(카드들이 `<button>`이라 span으로 짜여 있습니다).

## 파일 구성

- `index.html` — 앱 전체
- `manifest.json` / `sw.js` — PWA. **코드를 고치면 `sw.js`의 `CACHE` 버전을 올려야** 설치된 기기에 반영됩니다
- `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` — 앱 아이콘
- `DEPLOY.md` — 배포 가이드

## 데이터 출처

공개된 대한민국 행정구역 TopoJSON(2018년 기준, 구형 KOSTAT 코드: 11 서울 … 39 제주)을 사용합니다. 최신 행정구역과 차이가 있을 수 있습니다.
