# MY KOREA JOURNEY

가족이 함께 대한민국 방문지를 기록하고 다음 여행을 계획하는 여행 다이어리 웹앱. 서버 없이 `index.html` 한 파일로 동작합니다.

## 실행

정적 웹앱이므로 GitHub Pages, Vercel, Netlify 등에 그대로 배포할 수 있습니다. **배포 방법은 [DEPLOY.md](DEPLOY.md)를 참고하세요.**
로컬에서 미리 보려면 이 폴더에서 정적 서버를 하나 띄우면 됩니다 (예: VS Code의 Live Server 확장, 또는 `npx serve`).

## 주요 기능
- 대한민국 시·군·구 여행 지도, 방문 / 가고 싶은 곳 기록, 검색
- 지역별 날짜·제목·메모·만족도·참여 가족·**사진(최대 3장)** 기록
- 가족 구성원 등록 및 태그 (아바타 표시)
- 가족 여행 계획: 목적지·일정·**숙소·교통편·예산**·참여 가족·준비 체크리스트·사진, D-day 카드
- 여행 계획 완료 처리 시 지도에 자동으로 방문 기록 반영
- 여행률 및 최근 여행 통계, 여행 배지
- **우리 가족 여행 지도를 PNG 이미지로 저장** (SNS/카카오톡 공유용 키프세이크)
- **우리 가족 이름 설정** — 앱 제목이 "OO네 가족 여행일기"로 바뀝니다 (⚙️ 설정)
- **다른 가족에게 앱 소개하기** — 배포 링크를 공유하면 그 가족은 자기만의 새 기록을 시작할 수 있습니다 (기기별로 완전히 독립된 데이터)
- JSON 백업 / 복원 (가족·계획·사진 포함) — 기기 교체·브라우저 데이터 삭제 대비용
- 모바일 우선 UI: 하단 탭(지도 / 계획 / 기록), 상단 고정 설정 버튼
- **지도 확대/축소·이동**: 핀치 줌과 드래그, 그리고 +/− /전체보기 버튼 (250개 시·군·구를 작은 화면에서도 정확히 선택 가능)
- **풀블리드 지도**: 모바일에서 지도가 화면을 가득 채우고, 검색·컨트롤이 그 위에 겹쳐지는 지도 앱 표준 레이아웃
- **바텀시트**: 기록·계획 입력창이 하단에서 올라와 한 손 조작에 적합 (모든 터치 대상 44px 이상, 입력 글씨 16px로 iOS 자동 확대 방지)
- 검색 결과를 누르면 해당 지역으로 지도가 자동 확대
- **시·도별 파스텔 컬러**: 방문한 지역이 시·도마다 다른 색으로 칠해져, 지도가 조각보처럼 알록달록해지고 어느 지방을 탐험했는지 한눈에 보입니다
- **부드러운 감성 팔레트**: 로즈·라벤더·피치 톤의 파스텔 배색

## 성능 메모
지도는 250개 path를 렌더링하므로, 다음 두 가지를 지켜야 모바일에서 부드럽게 움직입니다.
- `.district`에 `filter`(drop-shadow 등)를 걸지 마세요. path마다 오프스크린 렌더가 생겨 팬/줌이 크게 느려집니다. 그림자가 필요하면 지도 컨테이너에만 `box-shadow`를 쓰세요.
- 확대 배율에 맞춘 선 굵기는 JS로 매 프레임 다시 칠하지 말고 CSS `vector-effect: non-scaling-stroke`에 맡기세요.
- 움직이는 지도 위에 겹치는 요소의 `backdrop-filter`는 모바일에서 해제되어 있습니다(매 프레임 재합성 방지).
- **PWA**: 홈 화면에 설치 가능, 서비스 워커가 지도 데이터까지 캐싱해 오프라인에서도 실행
- Web Share API 지원 (달성률 공유)
- localStorage 용량 초과 시에도 앱이 깨지지 않고 안내 메시지 표시

## 파일 구성
- `index.html` — 앱 전체 (마크업·스타일·로직)
- `manifest.json` — PWA 매니페스트
- `sw.js` — 오프라인 캐싱용 서비스 워커 (배포 후 코드 갱신 시 캐시 버전 문자열을 올려주세요)
- `icon.svg` — 앱 아이콘 (원하는 로고로 교체 가능)
- `DEPLOY.md` — 배포 가이드

## 데이터
지도는 공개된 South Korea administrative division TopoJSON을 사용합니다. 현재 MVP는 2018년 기준 시군구 데이터 URL을 사용하므로, 실제 서비스 공개 전에는 최신 행정구역 데이터로 교체하는 것을 권장합니다.

## 데이터 저장 방식
모든 기록은 그 브라우저의 localStorage에만 저장됩니다 — 서버나 계정이 없습니다. 즉 같은 가족이라도 아빠 폰과 엄마 폰의 기록은 자동으로 합쳐지지 않습니다(각자 따로 기록되거나, 한 기기를 같이 씀). 여러 가족이 같은 배포 주소를 열어도 서로의 기록을 볼 수 없고 섞이지도 않습니다 — 기기(브라우저)마다 독립적입니다.
